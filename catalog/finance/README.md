# Finance catalog

This folder is **not** a runtime tool registry.

- **Tool SoT:** Java `am-mcp-server` via MCP `list_tools` (fin-agent caches with `MCP_TOOL_CACHE_TTL_SECONDS`)
- **artifactType:** `fin-portfolio-agent/shared/formatters/artifact_resolver.py`
- **Widgets:** Flutter maps `artifactType` → widget (not this repo)

See `MCP_FREEZE.md` for how to add tools without bringing back a static catalog.
